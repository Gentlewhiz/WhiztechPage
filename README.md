# Whiz Portfolio

A modern personal portfolio built to showcase my work, frontend development skills, and approach to building thoughtful web experiences.

The portfolio is built with React and Tailwind CSS, with an emphasis on responsive design, clean interfaces, performance, accessibility, and maintainable frontend architecture.

## Overview

This portfolio represents my work and growth as a frontend developer.

Rather than treating a portfolio as a collection of static pages, I designed it as an interactive experience that demonstrates how I approach frontend development through real projects, thoughtful interactions, and attention to implementation details.

The project focuses on:

- Responsive and accessible interfaces
- Clean component architecture
- Performance-conscious development
- Interactive UI and motion
- Maintainable React code
- Consistent visual design
- Modern frontend development practices

## Features

### Responsive Design

The interface is designed to work across desktop, tablet, and mobile screen sizes while maintaining a consistent visual hierarchy and usable interaction patterns.

### Interactive UI

The portfolio uses carefully controlled animations and interactions to create a more engaging experience without allowing motion to overwhelm the content.

### Project Showcase

Projects are presented as the primary proof of my frontend capabilities, including relevant technologies, descriptions, and links where available.

### Performance Focus

The implementation considers common frontend performance concerns such as efficient rendering, optimized assets, animation performance, and minimizing unnecessary work in the browser.

### Accessibility

The project aims to follow practical accessibility principles, including semantic HTML, keyboard navigation, appropriate contrast, meaningful labels, and reduced-motion support.

## Design Philosophy

The visual direction combines minimalism, subtle neumorphism, restrained glass effects, atmospheric lighting, and strong typography.

The goal is not to fill the interface with visual effects.

Every interaction should have a purpose.

The design prioritizes:

> Clarity over decoration.  
> Interaction over gimmicks.  
> Real projects over artificial social proof.  
> Quality over unnecessary complexity.
